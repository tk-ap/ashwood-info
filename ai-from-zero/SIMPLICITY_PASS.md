# AI from Zero — Simplicity Pass

Approved direction: reduce the landing page to a short learning path. Preserve deeper references and interactive tools, but move them behind the first layer.

Primary visitor flow:

1. Start with something you already do.
2. Use AI for the lightest useful job.
3. Learn what an agent is only when repetition/coordination makes it useful.
4. Keep human judgment and permission boundaries explicit.
5. Go deeper one concept at a time.
6. Try the Build Gate when deciding whether a more agentic build is warranted.

The ecosystem is supporting evidence/case study, not required vocabulary.
