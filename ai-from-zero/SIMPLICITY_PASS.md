# AI from Zero — Simplicity Pass

Approved direction: reduce reading burden while preserving useful UI behavior.

Keep:
- interactive task-choice behavior
- contextual result reveal
- copyable first-handoff template
- links into Continuity, Reference, Build Gate, and Build Journal
- the existing visual language unless a visual element itself impairs comprehension

Primary learning path:
1. Start with something you already do.
2. Use AI for the lightest useful job.
3. Learn what an agent is only when repetition or coordination makes it useful.
4. Keep human judgment and permission boundaries explicit.
5. Go deeper one concept at a time.
6. Try a concrete tool or bounded handoff.

The ecosystem is supporting evidence/case study, not required vocabulary.
