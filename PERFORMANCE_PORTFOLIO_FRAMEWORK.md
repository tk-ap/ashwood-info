# ASHWOOD Performance Portfolio Framework

## Purpose

Establish Performance as a first-class ASHWOOD creative-practice lane without collapsing it into Music or Modeling.

Public presentation should show a coherent performer identity across voice and on-camera work while preserving a hard boundary between rights-cleared portfolio material and private audition/casting material.

## Parent ASHWOOD work architecture

Performance does **not** replace Portfolio/Work. It is one of the primary bodies of work inside a broader multidisciplinary ASHWOOD structure.

Canonical public hierarchy:

- **Work** — multidisciplinary landing / umbrella
  - **Modeling**
  - **Performance**
    - Voice Only
    - On Camera
  - **Music**
  - **Words**
  - **Physical Works**
- **Builds**
- **About**
- **Connect**

Recommended top navigation:

**Work · Builds · About · Connect**

The Work landing should introduce each practice visually first—image, motion, sound, or artifact—using minimal explanatory copy. The organizing idea is one authored point of view expressed through multiple forms, not a hierarchy in which Performance becomes the dominant identity.

### Route migration

Preferred route structure:

- `/work` → multidisciplinary landing
- `/modeling` → modeling body of work
- `/performance` → voice + on-camera body of work
- `/music` → music
- `/words` → poetry / writing when ready
- `/physical-works` → physical art when ready

The existing `/portfolio` route currently functions as a Modeling page. Preserve inbound links during migration by treating `/portfolio` as a compatibility route to Modeling rather than deleting it outright.

Do not relabel Performance as the umbrella for the rest of the creative practice.

## Public information architecture

Target public route: `/performance`

Suggested sections:

1. **Voice Only**
   - Primary commercial / conversational reel
   - Optional selectable excerpts by mode when useful
2. **On Camera**
   - Cleared branded-content and commercial-demo work
3. **Selected Work**
   - Released or explicitly portfolio-cleared projects only
4. **Range / Current Direction**
   - Commercial VO
   - Conversational / distinctive voice
   - On-camera branded content
   - Presenter / narrative
   - Acting / character work as cleared material accumulates

Do not expose internal rights reasoning, archive strategy, audition notes, or implementation language on the public site.

## Three-layer material model

### 1. Private archive
System of record for auditions, casting sides, self-tapes, unreleased work, and unclear-rights material.

### 2. Professional submission library
Cleared reels and samples intended for agents, casting, collaborators, and direct outreach.

### 3. Public ASHWOOD portfolio
Only material with a defensible public-use basis.

## Production rules

- The public Performance page should feel like part of the same authored ASHWOOD system, not a casting-directory profile.
- Favor one strong reel and a small number of high-signal samples over a comprehensive dump.
- Use the final web-ready audio copy for playback; preserve the WAV as the professional master.
- Keep original audition files in the private archive as range/reference material.
- Re-record original-copy equivalents when a private audition demonstrates a useful mode but cannot be published.
- Workspace should treat completion of the voice reel and cleared performance pieces as creative/professional evidence.
- Public-site implementation should preserve existing ASHWOOD interaction and typography principles rather than introducing a separate performance-site visual language.
