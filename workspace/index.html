    Self · context intelligence
    
          
    How TK is wired — and what the system should do with that.
    
        
    
        
    Synthesis first. Evidence and interpretation stay distinct; manual input is for correction, not upkeep.
    
      
    
      
    
        
    
          
    Operating model
    
          
    How I work best
    
          
    Surface durable patterns in decision-making, pace, autonomy, communication, motivation and attention. Separate observed behavior from working interpretations.
    
          
    System use: this is the default context agents should consult before deciding how to present, sequence, escalate or hand off work.
    
        
    
        
    
          
    Context → behavior
    
          
    How the ecosystem should adapt
    
          
    Translate context into explicit behavior for AgentOS, ALVIRA, ailhat, ledgato and ASHWOOD instead of leaving personal context as passive biography.
    
          
    ContextImplicationSystem behavior
    
        
    
        
    
          
    Current context
    
          
    What is true right now
    
          
    Active priorities, constraints and chapter-level conditions. These may change quickly and should not be mistaken for durable identity.
    
        
    
        
    
          
    Patterns
    
          
    What keeps showing up
    
          
    Recurring strengths, preferences and useful tendencies supported by multiple observations. Confidence should rise only with evidence.
    
        
    
        
    
          
    Tensions
    
          
    Where the system should compensate
    
          
    Tradeoffs, friction and contradictions worth designing around—not labels to turn into identity.
    
        
    
        
    
          
    Review
    
          
    Confirm, correct, reject
    
          
    Manual input appears when the system has a specific uncertainty. Corrections should update context; Self should not require routine form maintenance.
    
        
    
      
    
      
    
        Supporting evidence & interpretive frameworks
        
    Inspect provenance, observations and optional reflective frameworks here. Interpretive lenses can prompt hypotheses; they do not become facts without supporting evidence.
