# ASHWOOD Universe — Field translation

## Reference and boundary

- Reference reviewed: [destinconrad.com](https://destinconrad.com/), captured 2026-11-24 with a live public-page scrape.
- Observed interaction grammar: enter a world first; make movement discoverable; use drag, zoom, and selection to reach named creative destinations.
- This is a translation, not a recreation. ASHWOOD keeps its existing editorial typography, warm/paper theme system, copy, public routes, and creative archive. It does not reuse Destin Conrad's logo, visual assets, text, font choice, color palette, or island/game framing.
- A full-page screenshot was captured by the research service but was not pixel-inspectable in this execution environment. Exact visual values from the reference are therefore deliberately not treated as implementation targets.

## Implementation choices

| Reference principle | ASHWOOD field response |
| --- | --- |
| World before menu | The existing Universe is framed as a `Field guide`; the static index remains below it. |
| Direct manipulation | Fine-pointer desktop users can drag empty field space and scroll to change distance. Selecting a signal brings that thread toward center. |
| Clear destinations | Every signal still opens an established ASHWOOD route; held material remains visibly non-public. |
| Input guidance | The field prints its available controls and includes a reset action plus a live view scale. |
| Alternate grammar | Mobile remains a linear signal list. Reduced-motion users get the stable map/index with navigation controls removed. |
| Immediate offer | The opening is a concise threshold: one all-field action and three real group routes that scroll, filter, and visibly arrive at the map. |

## Acceptance boundaries

1. No new media is introduced; existing public routes and approved assets remain canonical.
2. The map never becomes the only way to find work: filters, inspector, index, and `noscript` links remain available.
3. The feature is preview-only until TK visually approves it. Vercel production remains outside this work.
4. The Music signal may show a verified Vercel preview as a read-only frame. Its form cannot submit inside the Universe; the canonical Music route remains separate and the external preview link is explicit.
