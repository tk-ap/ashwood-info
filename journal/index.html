00NOW / ECOSYSTEM BRIEF

Building the distance between knowing and doing.

The ecosystem is becoming a set of distinct products around a shared problem: how useful intelligence becomes when context is durable, attention is directed, action is governed, and execution is real.

ALVIRA

Context Intelligence: build, reflect on, update, own, and reuse the understanding AI needs.

ailhat

Portfolio Intelligence: identify what across a portfolio deserves attention next, and why.

LEDGATo

Operational reality: test whether agent authority and orchestration remain inside the intended boundaries at execution time.

FOUNDATIONAL LAYER

Governed Agent Workforce

Not a fourth public product. It is the execution substrate running through the ecosystem: agentic harness leverage, handoffs, permissions, skills, acceptance gates, and governed execution that products can call when action is appropriate.

01CURRENT BETS

What would have to be true?

The journal should make the wager legible—not only the output. Each bet includes the evidence I need and the condition that would change my mind.

BET 01 · ALVIRA

Maintained, inspectable, user-owned Context can make repeated AI work materially better.

EVIDENCE NEEDED

People return, correct, deepen, Reflect, and reuse Context—and notice a real improvement in continuity and judgment.

WHAT WOULD CHANGE MY MIND

If ongoing Context adds little beyond a static profile, the product should narrow.

BET 02 · ailhat

Portfolio intelligence is worth teaching.

EVIDENCE NEEDED

Cross-product signals reveal opportunity, risk, drift, or work more usefully than independent host-native monitoring.

WHAT WOULD CHANGE MY MIND

If users only want platform-native monitoring, the category thesis is too broad.

BET 03 · LEDGATo

The gap between intended agent authority and runtime reality is painful enough to govern.

EVIDENCE NEEDED

Execution-time checks surface meaningful mismatches or accountability gaps existing controls do not resolve cleanly.

WHAT WOULD CHANGE MY MIND

If existing platform controls are already sufficient, another layer is unnecessary.

04FACILITATION

Observation can become participation.

Testing and sponsorship are different. Existing products can invite users to test and give feedback. Build Sponsorship is reserved for a genuinely unfinished, separately scoped task with a concrete proof target, execution budget, and human acceptance gate.

ALVIRA · FOUNDING BETA · NOT A SPONSORSHIP REQUEST

Test the living Context loop.

ALVIRA is already built. This invitation is for product use and candid feedback—not money to build ALVIRA. A small number of people receive complimentary permanent access under an approved account so the existing product can be tested in real repeated use.

Whether the workflow, UI, relevance, continuity, Reflect experience, and ownership model make AI meaningfully more useful over repeated use.
WHY LIMITED
The cohort stays small enough to learn from individual usage rather than accumulate anonymous signups.
CANDIDATE SPONSORSHIP · LEDGATo

Move runtime proof from interface to execution.

This is only a valid sponsorship candidate if the runtime proof remains unfinished after scoping. The sponsorable unit is not “build LEDGATo”; it is one bounded implementation that makes a specific production-runtime proof demonstrable, instrumented, and independently reviewable.

STATUS
Scoping only. No funding request is active until the unfinished work, acceptance criteria, and execution budget are concrete.
VALIDITY GATE
If the work is already complete, required anyway as routine maintenance, or cannot be separated into a bounded proof target, it is not eligible for Build Sponsorship.
AGENT EXECUTION COST
A real range must come from the scoped implementation plan before sponsorship opens. No placeholder number is presented as evidence.
HUMAN OVERSIGHT
Deployment review, boundary verification, and final acceptance remain human-gated.
COMPLEXITY / CONFIDENCE
Published only after the runtime path and test surface are scoped.
WHAT SPONSORSHIP UNLOCKS
A defined execution budget for that specific unfinished proof, with progress and evidence returned to the Journal rather than funds handed directly to an autonomous agent.

Sponsorship eligibility rule: the work must be unfinished, optional or accelerative rather than pretending to fund something already built, separable into a bounded task, costed before money is requested, and tied to observable acceptance criteria. Completed products stay in the Journal as evidence; they are not retroactively turned into funding asks.
